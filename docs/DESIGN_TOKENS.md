# توکن‌های طراحی الو کپسول

تم روشن و فنی/خدماتی با نارنجی. همه‌ی رنگ‌ها فقط در `@theme` فایل `src/app/globals.css` تعریف می‌شوند و کامپوننت‌ها هیچ رنگ خامی (هگز/rgb) نمی‌نویسند؛ تغییر تم فقط با عوض کردن مقدار همین توکن‌هاست.

## نقش توکن‌ها

| توکن | مقدار | کاربرد |
|---|---|---|
| `brand` | `#F97316` | آیکون، خط و المان‌های بزرگ تزئینی — **هرگز متن معمولی** |
| `brand-strong` | `#C2410C` | دکمه‌ی اصلی با متن سفید، متن/لینک برجسته |
| `brand-soft` | `#FFF7ED` | پس‌زمینه‌ی جعبه‌های اطلاع‌رسانی (مثل شرایط خدمت) |
| `ink` | `#1C1917` | متن اصلی، هدر/فوتر تیره |
| `muted` | `#57534E` | متن ثانویه |
| `surface` / `surface-alt` | `#FFFFFF` / `#FAFAF9` | پس‌زمینه |
| `border*` | `#E7E5E4` … `#78716C` | خط‌ها و حاشیه‌ها (مویی، کنترل، برجسته، فوکوس) |
