# فهرست جای‌نگهدارها و داده‌های نمونه (باید توسط الو کپسول تکمیل شود)

هر ادعای واقعی کسب‌وکار (سابقه، آمار، آدرس، زمان ارسال، شرایط) عمداً ساخته نشده و با `{{تکمیل توسط الو کپسول: …}}` علامت خورده است. `npm run seo:audit` این علامت‌ها را در HTML گزارش می‌کند و تا رفعشان انتشار ممنوع است.

## الف) علامت‌های `{{تکمیل توسط الو کپسول: …}}`

| محل (پنل ادمین)                | مورد                                                                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| تنظیمات ← کسب‌وکار و خدمت      | نشانی محل تحویل حضوری (`business.pickupAddress`)                                                                                                     |
| تنظیمات ← کسب‌وکار و خدمت      | متن پیش‌فرض شرایط شارژ: شرایط پذیرش کپسول خالی (سالم بودن بدنه و شیر، تاریخ آزمایش، آنچه در صورت عدم پذیرش رخ می‌دهد) — **بازبینی کارفرما لازم است** |
| تنظیمات ← صفحه‌ی اصلی          | متن «درباره ما»: سابقه و معرفی کوتاه (`home.about.text`)                                                                                             |
| تنظیمات ← سئو                  | نام حقوقی ثبت‌شده‌ی کسب‌وکار (`org.legalName`)                                                                                                       |
| تنظیمات ← عمومی                | ایمیل و نشانی (پیش‌فرض `site-content.ts`؛ فوتر و صفحه‌ی تماس)                                                                                        |
| صفحات ← درباره ما              | سال شروع فعالیت و داستان شکل‌گیری؛ روش کار و تجهیزات                                                                                                 |
| صفحات ← تماس                   | ساعات پاسخگویی تلفنی                                                                                                                                 |
| صفحات ← سوالات متداول          | شرایط سفارش تعدادی/کارگاهی/صنعتی؛ دو پاسخ خالی دیگر                                                                                                  |
| صفحات ← شرایط ارسال            | زمان تقریبی آماده‌سازی و تحویل؛ آدرس و ساعت تحویل حضوری؛ شرایط تحویل (مثلاً گیرنده در دسترس نباشد)                                                   |
| صفحات ← مرجوعی و لغو           | تا چه مرحله‌ای سفارش قابل لغو است و بازگشت وجه؛ شرایط مرجوعی/جایگزینی؛ روش و زمان بازگشت وجه                                                         |
| صفحات ← حریم خصوصی             | نحوه‌ی درخواست اصلاح یا حذف اطلاعات و راه تماس                                                                                                       |
| محصولات                        | توضیحات کامل «شارژ کپسول گاز بوتان»، «شارژ کپسول اکسیژن ۴۰ کیلویی»؛ مشخصات فنی و گارانتی «کپسول ۱۱ کیلویی»؛ مشخصات و قیمت واقعی «پیک‌نیک»            |
| پیش‌فرض کد (`site-content.ts`) | «سابقه و داستان برند» (بخش درباره ما)، «سال شروع و داستان»، «روش کار و تجهیزات»، «زمان تقریبی آماده‌سازی و تحویل» (متن ارسال و نگهداری صفحه‌ی محصول) |

## ب) داده‌ی نمونه‌ی seed که علامت ندارد ولی واقعی نیست

| مورد                                       | وضعیت                                                                                                                    |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| هزینه‌ی «ارسال با پیک» = ۱۰۰٬۰۰۰ تومان     | عدد نمونه؛ هزینه‌ی واقعی و آستانه‌ی رایگان (۱۰ عدد، طبق سند) را تعیین کنید                                               |
| کارت بانکی «بانک نمونه»                    | شماره‌ی غیرواقعی؛ قبل از انتشار حتماً عوض شود                                                                            |
| کد تخفیف `WELCOME10`                       | نمونه؛ حذف یا عوض شود                                                                                                    |
| قیمت‌های چهار محصول نمونه                  | شارژ بوتان (۸۰۰٬۰۰۰ / ۲٬۲۰۰٬۰۰۰ / ۲٬۴۵۰٬۰۰۰ / ۳٬۸۵۰٬۰۰۰) و کپسول ۱۱ کیلویی (۶٬۰۰۰٬۰۰۰) از سند؛ پیک‌نیک ۵۰۰٬۰۰۰ **نمونه** |
| وزن ارسال متغیرها                          | پیشنهاد خودکار (وزن واحد)؛ وزن واقعی کپسول‌ها را وارد کنید                                                               |
| ساعت تحویل «۹ صبح تا ۶ عصر»                | از سند؛ تأیید شود                                                                                                        |
| لوگو، favicon، تصاویر هیرو/محصول/درباره ما | جای‌نگهدار                                                                                                               |
| الگوهای پیامک                              | باید در پنل ملی پیامک الو کپسول جداگانه ثبت و تأیید شوند                                                                 |
| ادمین seed                                 | شماره‌ی `ADMIN_SEED_PHONE`                                                                                               |
