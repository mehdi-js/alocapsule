# فهرست جای‌نگهدارها و داده‌های نمونه (باید توسط الو کپسول تکمیل شود)

هر ادعای واقعی کسب‌وکار (سابقه، آمار، آدرس، زمان ارسال، شرایط) عمداً ساخته نشده و با `{{تکمیل توسط الو کپسول: …}}` علامت خورده است. `npm run seo:audit` این علامت‌ها را در HTML گزارش می‌کند و تا رفعشان انتشار ممنوع است.

## الف) علامت‌های `{{تکمیل توسط الو کپسول: …}}`

| محل (پنل ادمین)                | مورد                                                                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| تنظیمات ← کسب‌وکار و خدمت      | نشانی محل تحویل حضوری (`business.pickupAddress`)                                                                                                     |
| تنظیمات ← کسب‌وکار و خدمت      | متن پیش‌فرض شرایط شارژ: شرایط پذیرش کپسول خالی (سالم بودن بدنه و شیر، تاریخ آزمایش، آنچه در صورت عدم پذیرش رخ می‌دهد) — **بازبینی کارفرما لازم است** |
| تنظیمات ← صفحه‌ی اصلی          | متن «درباره ما»: سابقه و معرفی کوتاه (`home.about.text`)                                                                                             |
| تنظیمات ← سئو                  | نام حقوقی ثبت‌شده‌ی کسب‌وکار (`org.legalName`)                                                                                                       |
| تنظیمات ← عمومی                | ایمیل و نشانی (پیش‌فرض `site-content.ts`؛ فوتر و صفحه‌ی تماس)                                                                                        |
| صفحات ← درباره ما              | سال شروع فعالیت و داستان شکل‌گیری؛ روش کار و تجهیزات                                                                                                 |
| صفحات ← تماس                   | ساعات پاسخگویی تلفنی                                                                                                                                 |
| صفحات ← سوالات متداول          | شرایط سفارش تعدادی/کارگاهی/صنعتی؛ دو پاسخ خالی دیگر                                                                                                  |
| صفحات ← شرایط ارسال            | زمان تقریبی آماده‌سازی و تحویل؛ آدرس و ساعت تحویل حضوری؛ شرایط تحویل (مثلاً گیرنده در دسترس نباشد)                                                   |
| صفحات ← مرجوعی و لغو           | تا چه مرحله‌ای سفارش قابل لغو است و بازگشت وجه؛ شرایط مرجوعی/جایگزینی؛ روش و زمان بازگشت وجه                                                         |
| صفحات ← حریم خصوصی             | نحوه‌ی درخواست اصلاح یا حذف اطلاعات و راه تماس                                                                                                       |
| محصولات                        | توضیحات کامل «شارژ کپسول گاز بوتان»، «شارژ کپسول اکسیژن ۴۰ کیلویی»؛ مشخصات فنی و گارانتی «کپسول ۱۱ کیلویی»؛ مشخصات و قیمت واقعی «پیک‌نیک»            |
| پیش‌فرض کد (`site-content.ts`) | «سابقه و داستان برند» (بخش درباره ما)، «سال شروع و داستان»، «روش کار و تجهیزات»، «زمان تقریبی آماده‌سازی و تحویل» (متن ارسال و نگهداری صفحه‌ی محصول) |

## ب) داده‌ی نمونه‌ی seed که علامت ندارد ولی واقعی نیست

| مورد                                       | وضعیت                                                                  |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| کارت بانکی «بانک نمونه»                    | شماره‌ی غیرواقعی؛ قبل از انتشار حتماً عوض شود                          |
| کد تخفیف `WELCOME10`                       | نمونه؛ حذف یا عوض شود                                                  |
| قیمت محصولات (۸ شارژ/خرید)                 | از سند SEO.md (به‌روزرسانی ۲۱ شهریور ۱۴۰۵)؛ کارفرما در ادمین تأیید کند |
| وزن ارسال ترکیب‌ها                         | نمونه (= ظرفیت کپسول بر حسب کیلوگرم)؛ وزن واقعی کپسول‌ها را وارد کنید  |
| ساعت تحویل «۹ صبح تا ۶ عصر»                | از سند؛ تأیید شود                                                      |
| لوگو، favicon، تصاویر هیرو/محصول/درباره ما | جای‌نگهدار                                                             |
| الگوهای پیامک                              | باید در پنل ملی پیامک الو کپسول جداگانه ثبت و تأیید شوند               |
| ادمین seed                                 | شماره‌ی `ADMIN_SEED_PHONE`                                             |

## پ) فاز P2 (محتوای seed — SEO.md §۱۰ و §۱۱)

### ۱. علامت‌های `{{تکمیل توسط الو کپسول: …}}` در متن‌های seed

| محل                                        | مورد                                                                                                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| محصول شارژ ۱۱ / ۲۵ / ۳۳ / ۵۰ (سوال متداول) | مدت مصرف ۱۱ کیلویی (فقط اگر ادعای قابل اتکا دارید)؛ توصیه‌ی ایمنی نگهداری ۲۵ کیلویی؛ شرایط سفارش چندکپسولی برای کسب‌وکار (۳۳)؛ شرایط تحویل کپسول سنگین (۵۰) |
| محصول خرید ۱۱ / ۲۵ / ۳۳ / ۵۰ (سوال متداول) | گارانتی کپسول نو (۱۱)؛ مشخصات فنی (وزن خالی، ابعاد، سازنده) برای ۲۵، ۳۳ و ۵۰                                                                                |
| کپسول دست دوم                              | قیمت هر اندازه و وضعیت تحویل، شرایط تست سلامت (سپس فعال‌سازی و برداشتن noindex)                                                                             |
| پیک‌نیک                                    | سایزها و قیمت‌ها (سپس فعال‌سازی و برداشتن noindex)                                                                                                          |
| اکسیژن ۴۰ لیتری / گازهای صنعتی             | جزئیات خدمت: شرایط پذیرش کپسول، مجوزها و استانداردها، فهرست گازها و ظرفیت‌ها (متن کارفرما در سند نبود؛ پیش‌نویس عمومی نوشته شد، بدون ادعای پزشکی)           |
| hub شارژ (سوال متداول)                     | شرایط پذیرش کپسول خالی (همان `service.defaultTerms`)                                                                                                        |
| صفحه‌ی درباره ما                           | متن «همراه مطمئن شما…»، «چرا ما را انتخاب کنید؟»، ماموریت، چشم‌انداز، ارزش‌ها — از متن فعلی سایت (در سند نبود؛ ساختار H2/فهرست آماده است)                   |
| صفحه‌ی تماس                                | متن مقدمه‌ی سایت فعلی؛ ساعات پاسخگویی تلفنی                                                                                                                 |
| صفحه‌ی قوانین (`/terms`)                   | قوانین سفارش (ثبت، پرداخت، لغو، تحویل)                                                                                                                      |

### ۲. متن‌هایی که کارفرما باید بازبینی کند (فهرست بند ۱۰.۲)

- ۸ صفحه‌ی اندازه (شارژ ۱۱ / ۲۵ / ۳۳ / ۵۰ و خرید ۱۱ / ۲۵ / ۳۳ / ۵۰): پیش‌نویس‌اند؛ کاربرد اندازه‌ها (خانگی / رستوران / صنعتی) طبق راهنمای پیش‌نویس سند است و **تأیید کارفرما لازم دارد**.
- متن hub شارژ و خرید، بلوک محتوای صفحه‌ی اصلی، متن کپسول دست دوم، پیک‌نیک، اکسیژن و گازهای صنعتی.
- متن «شارژ کپسول اکسیژن» و «گازهای صنعتی» عیناً از کارفرما در سند نیامده بود؛ پیش‌نویس عمومی ساخته شد.

### ۳. داده‌ی seed که واقعی نیست یا باید کارفرما وارد کند

- هزینه‌ی «ارسال عادی» و «ارسال فوری»: هر دو **غیرفعال** seed شده‌اند (هزینه‌ی صفر یعنی ارسال رایگان)؛ هزینه را وارد و فعال کنید.
- قیمت کپسول دست دوم (۸ ترکیب) و پیک‌نیک (مقدار سایز و قیمت): خالی و غیرفعال.
- وزن ارسال ترکیب‌ها: نمونه.
